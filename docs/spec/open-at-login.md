# Open at login

Calendrop can open by itself when the user logs in, so it is running before the
first meeting of the day.

- It is off until the user turns on **Open at login** in its General settings.
- The choice is macOS's own Login Items entry for Calendrop. Changing it in
  System Settings changes it in Calendrop's settings too, and the other way
  round.
- When macOS asks the user to allow it first, the settings say so and offer to
  open System Settings.
- The choice belongs to the Mac, not to the settings shared through iCloud
  Drive.
